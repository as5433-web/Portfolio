# Andrew Soleiman's Portfolio

A personal portfolio for my website development assignment, built with plain HTML, CSS, and JavaScript. My focus is Electronics & Computer Engineering Technology, low-voltage circuits, and analog audio systems.

GitHub Pages URL: https://as5433-web.github.io/Portfolio/

Local changes appear on GitHub Pages only after they are committed and pushed to `main`.

## Pages

- `index.html`: introduction, animated waveform, background, featured amplifier, skills, and LinkedIn contact sections.
- `about.html`: education at CCM and NJIT, selected electronics coursework, work experience, and future study goals.
- `projects.html`: guitar amplifier, electronic calculator, and Arduino rover projects.
- `skills.html`: demonstrated electronics capabilities, tool experience, and professional skills linked to supporting projects.
- `contact.html`: LinkedIn link.

All five pages use a professional navy and blue design with pink accents, system fonts, shared navigation, responsive styling, and a light/dark mode toggle. Home has animations that respect reduced-motion preferences. Projects includes report-based build descriptions and photos.

## View locally

Double-click `index.html` to open the site in a browser. Use the navigation to visit the other pages. Alternatively, open this folder in VS Code and use Microsoft's Live Preview extension. No installation, build step, backend, or API keys are required. Theme persistence depends on browser storage availability, particularly when opening local files directly.
